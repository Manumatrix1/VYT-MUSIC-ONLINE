2. Escribe: `Developer: Reload Window`
3. Enter

## 🔥 SI SIGUE LENTO - ACCIONES ADICIONALES

### A. Desactivar TODAS las extensiones temporalmente
1. `Ctrl + Shift + X` (Abrir extensiones)
2. Clic en el ícono de filtro
3. Seleccionar "Desactivar todas las extensiones"
4. Recargar ventana
5. Si mejora, reactivar de una en una para encontrar la culpable

### B. Extensiones comunes problemáticas:
- ❌ **ESLint** - Desactívala si no la usas
- ❌ **Prettier** - Desactívala si no la usas  
- ❌ **GitLens** - MUY pesada, desactívala
- ❌ **Live Server** - Desactívala cuando no la uses
- ❌ **IntelliCode** - Consume recursos
- ✅ Solo mantén las ESENCIALES

### C. Abrir VS Code en modo seguro (sin extensiones)
```cmd
code --disable-extensions
```

### D. Aumentar memoria de VS Code
Edita el archivo que crea el script o ejecuta:
```cmd
code --max-memory=4096
```

### E. Verificar procesos de Node.js
```powershell
# Ver procesos Node activos
Get-Process node

# Si hay muchos, matarlos:
Get-Process node | Stop-Process -Force
```

## 📊 DIAGNOSTICAR PROBLEMAS

### Ver uso de recursos en VS Code
1. `Ctrl + Shift + P`
2. `Developer: Open Process Explorer`
3. Identificar procesos que usan mucha CPU/RAM
4. Si ves extensiones problemáticas, desactívalas

### Ver logs de VS Code
1. `Ctrl + Shift + P`
2. `Developer: Toggle Developer Tools`
3. Tab "Console" - ver errores

## ⚙️ CONFIGURACIONES ADICIONALES

### Si trabajas con archivos grandes:
Agrega a `.vscode/settings.json`:
```json
{
  "files.maxMemoryForLargeFilesMB": 4096,
  "search.maxResults": 1000
}
```

### Desactivar Git completamente (extremo):
```json
{
  "git.enabled": false
}
```

## 🆘 ÚLTIMA OPCIÓN - REINSTALAR VS CODE

Si nada funciona:

1. **Hacer backup de configuración:**
   - Copia `%APPDATA%\Code\User\settings.json`
   - Copia extensiones que quieras mantener

2. **Desinstalar VS Code completamente:**
   - Panel de Control → Desinstalar programas
   - Eliminar carpeta: `%APPDATA%\Code`
   - Eliminar carpeta: `%USERPROFILE%\.vscode`

3. **Instalar versión limpia:**
   - Descargar desde https://code.visualstudio.com/
   - Instalar SIN extensiones inicialmente
   - Copiar solo `.vscode/settings.json` de este proyecto

4. **Instalar extensiones una por una:**
   - Solo las imprescindibles
   - Probar rendimiento después de cada una

## 💡 TIPS PREVENTIVOS

1. **Cerrar archivos que no uses**: No dejes 20 tabs abiertas
2. **Cerrar terminales**: Cada terminal consume recursos
3. **No abrir carpetas gigantes**: Solo abre la carpeta del proyecto específico
4. **Reiniciar VS Code diariamente**: No dejes VS Code abierto 24/7
5. **Actualizar VS Code**: Las versiones nuevas suelen ser más rápidas
6. **SSD vs HDD**: Si tu proyecto está en HDD, muévelo a SSD
